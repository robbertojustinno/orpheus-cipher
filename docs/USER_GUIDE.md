# ORPHEUS User Guide

## Instalação e ativação

Execute o instalador autorizado no Windows 10/11 x64. Node.js, npm, Rust, Cargo e ferramentas de compilação não são necessários para o usuário final. Na primeira abertura, informe a licença recebida e aguarde a confirmação criptográfica. A chave completa não volta a ser exibida.

## Interface e campanha

Após a autorização, o painel ORPHEUS inicia a experiência de detecção e restaura sessões posteriores automaticamente. Use `INICIAR SEQUÊNCIA` para liberar a primeira Caixa. Cada Caixa contém briefing, evidências, pistas progressivas e um campo de validação. Algumas respostas exigem leitura e interpretação de **CIPHER — Protocolo Orpheus**. Este manual não contém soluções.

## Terminal

Clique no prompt e use `help` para listar comandos públicos. O terminal é um parser interno: ele não é CMD, PowerShell ou Bash e não executa comandos do sistema operacional. Respostas submetidas pelo comando `answer` são mascaradas no histórico da sessão.

## Pesquisa Profunda

Quick Search, Deep Search e Deep Dorks trabalham apenas com fontes públicas e consultas iniciadas pelo operador. RDAP/DNS são reais; providers indisponíveis são apresentados como indisponíveis, nunca como resultados fabricados. Use o modo privado para não salvar uma investigação.

## Privacidade

Username, hostname, plataforma e arquitetura personalizam localmente a experiência. O installation ID é aleatório e não usa fingerprint de hardware. Consultas OSINT e respostas de enigma podem sair da máquina somente quando o operador executa a ação correspondente. O ORPHEUS não lê arquivos pessoais, senhas, cookies ou histórico do navegador.

## Desinstalação

O progresso e a licença residem no diretório de dados do usuário. Preservá-lo permite restaurar a operação após reinstalação; removê-lo elimina a cópia local. Faça backup antes de qualquer limpeza manual. Builds sem assinatura de código podem gerar aviso SmartScreen legítimo do Windows.
